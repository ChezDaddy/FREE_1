Connexion Supabase

⏱ Keep-alive automatique
Un ping léger (SELECT id HEAD) est envoyé toutes les 4 minutes quand l'onglet est actif, pour éviter la mise en veille du projet Supabase Free tier (suspend après ~5–7 min d'inactivité).
Le ping se met en pause si l'onglet est masqué, et reprend à la réactivation.
Tables requises (SQL Supabase) :
chantiers · lots · factures · app_users

app_users :
CREATE TABLE app_users (id uuid primary key default gen_random_uuid(), email text unique not null, pwh text not null, role text not null default 'directeur', created_at timestamptz default now());

Mode hors-ligne (localStorage)

Sans Supabase configuré, l'application fonctionne en mode local.
Les données sont stockées dans le navigateur et non synchronisées.
Importez vos données locales vers Supabase une fois configuré.
